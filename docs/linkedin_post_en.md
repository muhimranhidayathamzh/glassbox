I built a language model from scratch, then built the tools to look inside it.

Glassbox is a 2.6M-parameter transformer that I trained on a laptop CPU in 3 hours. It runs entirely in your browser: no server, no API key.

Then I opened it up:
→ A sparse autoencoder splits its internal state into 2,048 readable features.
→ Steering with a single feature ("ball", "dog", "cat", ...) makes 83% of stories mention that concept, against 9% for a random direction of the same size.
→ A name guard reads those features before each token is chosen. Together with a regex it catches 71% of names it was never fitted on; the regex alone catches 52%. The price: about 2 in 100 other tokens are held back by mistake.

The part I care about most is the discipline:
• every number is generated by a script from the experiments, and CI checks the pages still match
• every claim is measured against a baseline
• selection rules were written down before the results came in
• negative results stay in: no induction heads formed, and the feature guard on its own does not beat a regex
