## Dead features

Dead = never active on the reconstruction tokens. The second column counts dead features whose pre-activation never went above zero (the ReLU then passes them no gradient at all); the rest had positive pre-activations but were always outranked by k other features. The AuxK loss is the fraction of the remaining reconstruction error that the dead features fail to explain (averaged over the last logging interval): close to 1 means AuxK was active but did not bring them back.

## SAE used by the web microscope

Rule (fixed in advance): the smallest k whose loss recovered is >= 85%; if none qualifies, the largest k.

Selected: **k = 8** (`runs/sae_k8`). Loss recovered 96.0%.

Read the percentage with care: mean ablation raises the loss from 1.76 to 7.36, so even 96.0% recovered leaves the selected SAE 12.7% above the clean loss. In hindsight the threshold is lenient for this model; it is kept because it was fixed before the results were seen. All three SAEs are available to later milestones.

SAE training: Adam, lr 0.008 (best of a short pilot, `results/sae_lr_pilot.json`), 8,000,000 tokens, batch 4096, AuxK (k_aux 64, coefficient 0.03125), seed 0.
