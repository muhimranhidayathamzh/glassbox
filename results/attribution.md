# Milestone 4: feature attribution, checked by ablation

Generated by `python -m glassbox.attribution`. Do not edit by hand.

300 cases from validation stories: the model reads a story up to a random position t and predicts the actual next token. Candidates are the SAE features active at the last 8 positions (mean 64.0 per case). Ground truth: remove one feature's contribution from the residual stream and measure the drop in the target token's logit.

## How well each estimate predicts the ablation

| estimate | mean Spearman correlation | top candidate matches |
|---|---:|---:|
| direct logit attribution | 0.166 | 56.0% |
| gradient x activation | 0.732 | 44.3% |
| activation only (baseline) | 0.161 | 10.0% |
| random order (floor) | -0.000 | 1.7% |

## What the ablations show

- Share of the total |effect| that comes from features at the predicting position t: 42.4% (the rest comes through attention from earlier positions).
- Median |effect| of a candidate: 0.024 logits; the largest per case has median 4.422.
- Candidates that push the target up (effect > 0): 56.5%.

DLA is the estimate named in the project brief; it only sees the direct path from the feature to the output, so it cannot credit features at earlier positions and ignores blocks after the SAE's layer. The browser's circuit graph therefore uses ablation itself, which is exact.
