# Milestone 6: name guard

Generated by `python -m glassbox.guard`. Do not edit by hand.

Task: at each position the model has read the story so far; is the next token the first token of a name? A guard that says yes hides that token (and the rest of the word) before it is shown.

## Data

- Name lexicon: 408 names found automatically in 186,751 training stories (capitalized mid-sentence at least 20 times, lowercase less than 2% of the time), minus 43 hand-listed capitalized non-names. Most frequent: Tim, Lily, Tom, Sue, Max, Ben, Sam, Mia, Lucy, Anna.
- Stories: 1,500 for calibration and 1,500 for testing, all from the validation split; 3,698 stories with other capitalized mid-sentence words (possible unlabelled names) were dropped.
- Test positions: 276,546, of which 10,359 are followed by a name (3.7%).
- New-names condition: every name replaced by one of 51 names that are not in the lexicon (e.g. Aiko, Anjali, Bayu, Bilal, Budi, Chidi), the same replacement within a story.

Classifiers are fitted, and all thresholds chosen for the best F1, on calibration stories with known names only. The new-names test therefore measures generalization to names never used for fitting.

Rows marked * were added after the first results: a strict threshold for the SAE classifier (the highest one that still catches 90% of calibration names), the combination that hides a word when either the regex or the SAE guard fires, and a probe on the last layer as a reference (the SAE, and so the guard, reads layer 2).

## Test: known names

| method | decides | precision | recall | F1 | false blocks / 1000 tokens |
|---|---|---:|---:|---:|---:|
| regex + name list | after the token is chosen | 0.999 | 1.000 | **1.000** | 0.0 |
| text classifier (previous 2 tokens) | before the token is chosen | 0.362 | 0.488 | **0.416** | 32.3 |
| residual-stream probe | before the token is chosen | 0.501 | 0.577 | **0.536** | 21.5 |
| SAE-feature classifier | before the token is chosen | 0.481 | 0.563 | **0.519** | 22.8 |
| single SAE feature #1223 | before the token is chosen | 0.147 | 0.326 | **0.202** | 71.1 |
| SAE-feature classifier, strict * | before the token is chosen | 0.239 | 0.897 | **0.377** | 107.2 |
| regex or SAE guard * | both | 0.622 | 1.000 | **0.767** | 22.8 |
| regex or SAE guard, strict * | both | 0.259 | 1.000 | **0.411** | 107.2 |
| residual-stream probe, last layer (reference) * | before the token is chosen | 0.544 | 0.629 | **0.583** | 19.8 |

The regex uses the same lexicon that defines the labels, and stories with other capitalized mid-sentence words were dropped, so its near-perfect score on known names holds by construction. The new-names test is the fair comparison.
