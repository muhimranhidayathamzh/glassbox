Glassbox

A small language model (… parameters), built from scratch and running entirely in your browser. No server, no API key.

Steering (experimental)

Push the story toward a concept: while the model writes, the direction of one sparse autoencoder feature is added to its internal state (the residual stream at layer 2). Strength 1 adds a vector as large as a typical internal state; large values break the text. Measured effects: results/steering.md.

Name guard

Hide names before they are shown. Before each token is chosen, a classifier reads the model's sparse-autoencoder features and predicts whether a name comes next; once a word is complete, an optional word check also hides known names and capitalized words in mid-sentence. Hover a hidden word to see why. Measured precision, recall and cost: results/guard.md.

With Show tokens on, each token is outlined and shaded by how surprising it was to the model (darker = less likely). Hover or tap a token to see its probability and the alternatives.

The model was trained on TinyStories (simple English stories for young children, license CDLA-Sharing-1.0), so that is the only kind of text it knows. It is not a chatbot: it continues whatever you write.

Temperature 0 always picks the most likely token. Top-k 0 means no top-k filter. The same seed and settings always give the same story.
