Glassbox

A small language model (… parameters), built from scratch and running entirely in your browser. No server, no API key.

With Show tokens on, each token is outlined and shaded by how surprising it was to the model (darker = less likely). Hover or tap a token to see its probability and the alternatives.

The model was trained on TinyStories (simple English stories for young children, license CDLA-Sharing-1.0), so that is the only kind of text it knows. It is not a chatbot: it continues whatever you write.

Temperature 0 always picks the most likely token. Top-k 0 means no top-k filter. The same seed and settings always give the same story.
